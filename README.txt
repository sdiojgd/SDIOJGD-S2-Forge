SDIOJGD S2 Forge

1. Double-click "SDIOJGD S2 Forge.vbs".
   The Forge opens in its own window, and a "SDIOJGD S2 Forge" shortcut with the Forge icon is
   put on your desktop. Next time just double-click that shortcut.
2. Close the Forge window (or press Quit) to stop it.

If the window doesn't open, double-click Start.bat instead: it does the same thing but shows a
black window with any error messages.

It uses the Python that comes with Blender, so nothing else needs installing.
It needs Blender installed (free, blender.org, 4.2 or newer): the Forge uses the Python that comes
with Blender. Unzip the whole folder first, don't run it from inside the zip.
If nothing opens, double-click Start.bat: it shows what's wrong.

Windows may ask "Do you want to open this file?" (Unknown Publisher) the first time, because it came
from the internet. Press Open. After that the Forge marks its own files as safe and it stops asking.
To skip it completely: before unzipping, right-click the zip, Properties, tick Unblock, OK.

Can't delete the folder? The Forge is still running: press Quit (or end "python" in Task Manager).

Log of the last port: app\logs\last_port.txt (also copied to SFM usermod\_s2port_log.txt)
